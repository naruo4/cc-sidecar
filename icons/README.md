# CC Sidecar icon

The fork uses the existing coral-red/white play-icon composition with a small
charcoal **CC** badge at the lower right to distinguish CC Sidecar.

The edit was made with the built-in image generation tool (imagegen skill),
then resized to the Chrome manifest sizes with macOS `sips`.
